# Concepts de sites Coda

Les maquettes sont de vrais composants HTML/CSS dans `src/components/mockup.tsx`,
avec quatre compositions originales : Maison Azur, Aura Botanique, Studio Élan
et Tempo. Les photos originales optimisées sont dans `../images/`.

Elles s’affichent dans le hero, la galerie et la fenêtre d’aperçu. Il ne s’agit
pas de captures de sites tiers. Toutes les marques sont fictives et présentées
comme des concepts, sans témoignages ni résultats clients inventés.
