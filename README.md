# Coda Agency

Site statique de Coda Agency, pensé en priorité pour le référencement autour de la création de sites web au Maroc.

## Structure
- Homepage minimaliste
- Page pilier `creation-site-web-maroc`
- Pages locales Casablanca, Tanger, Rabat, Marrakech, Agadir
- Pages `site-vitrine` et `site-ecommerce`
- Page `prix-site-web-maroc`
- Page secondaire `seo-geo-aeo`
- `robots.txt`, `sitemap.xml`, canonical, meta descriptions, données structurées, `llms.txt`, 404 et manifest

## Déploiement
Le repo est compatible avec GitHub Pages. Le fichier `CNAME` pointe vers `codaagency.co`. Les DNS doivent être configurés côté registrar avant activation du domaine personnalisé.

## À faire avant mise en production
1. Connecter le formulaire à une vraie adresse ou un endpoint de formulaire.
2. Ajouter l’image Open Graph officielle lorsque le branding final est prêt.
3. Vérifier le domaine dans Google Search Console et soumettre `/sitemap.xml`.
4. Ajouter les réalisations dès que des projets publics sont disponibles.
5. Enrichir les pages locales uniquement avec des informations réelles et utiles au fur et à mesure.
